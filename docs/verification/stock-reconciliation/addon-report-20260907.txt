--- etc/init.d/S39usb-coldplug (new file, full contents) ---
#!/bin/sh
case "$1" in
    start)
        printf "Reload USB drivers... "
        udevadm trigger --subsystem-match=usb --action=add
        udevadm settle --timeout=10
        echo "done"
        ;;
    *)
        echo "Usage: $0 {start}"
        exit 1
        ;;
esac

--- usr/sbin/uartmode (changed; see below) ---
kill_all() no longer runs `killall agetty login pppd midilink`; instead it
`fuser -k`s /dev/ttyS1 directly (TERM then KILL after 0.1s if still held),
plus `killall -KILL fluidsynth mpg123 mt32d`. The PPP localip/remoteip sed
pipeline gained a `169.254.*` (link-local) exclusion. pppd's exit status is
now inspected and a fatal-status message printed for a named set of codes.
A new mode "6" was added: launches /media/fat/snid under `RUST_LOG=info
taskset 1`, respawning on exit, guarded by /tmp/uartmode6 -- a binary and
mode this document has no other reference to. Full unified diff in
docs/stock-reconciliation.md §0.3.
